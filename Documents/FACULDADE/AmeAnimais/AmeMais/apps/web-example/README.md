# apps/web-example

Este app **não é** um dos sites reais do projeto — os sites reais são `apps/web-public` (site público) e `apps/web-admin` (painel administrativo).

`apps/web-example` existe só como material de estudo: mostra, de ponta a ponta, como um frontend Next.js consome o `apps/api` (feature `_example-demo`, camadas `route → controller → service → repository`). Use como referência de padrão ao criar a primeira feature real em `apps/web-public` ou `apps/web-admin` — ver [ADR 0003](../../docs/decisions/0003-frontend-feature-based.md).

Pode ser removido quando não fizer mais falta como referência.
