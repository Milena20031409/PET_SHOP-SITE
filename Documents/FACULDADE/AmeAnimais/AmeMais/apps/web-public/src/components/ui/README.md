# components/ui/

Só componentes genéricos de verdade (primitivos shadcn/ui, sem lógica de negócio) — usados por mais de uma feature. Não colocar aqui nada específico de uma funcionalidade; isso vai em `src/features/<feature>/components/`.

Ver [ADR 0003 — Organização do frontend: feature-based](../../../../docs/decisions/0003-frontend-feature-based.md).
